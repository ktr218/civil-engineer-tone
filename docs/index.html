바로 점검

AI가 쓴 초안이나 내가 쓴 글을 붙여넣으세요. 끝맺음·과장·마크다운·단위를 짚고 A~D 등급을 매깁니다. 원문을 함께 넣으면 바뀐 숫자·단위도 찾습니다. 글은 이 화면 밖으로 나가지 않습니다.

서버로 보내지 않고 이 브라우저 안에서만 검사합니다. 문서 종류를 고르면 더 정확합니다.

글을 붙여넣고 점검하기를 누르세요.

알아 두세요

팀마다 말투가 다르면요?

우리 팀이 쓴 문서 2~3개를 붙여넣고 “앞으로 이 문서들 말투에 맞춰줘”라고 하세요. 팀 예시가 지침보다 우선합니다.

매번 붙여넣어야 하나요?

아니요. ChatGPT는 GPT 만들기, Gemini는 Gem 만들기, Claude는 프로젝트의 지침 칸에 복사한 글을 한 번만 넣어 두면 됩니다. 지침은 6천 자가 안 돼 GPT 지침 칸(8,000자)에도 들어갑니다.

Claude 스킬로 등록할 수 있나요?

네. 아래 zip을 받아 claude.ai 설정 → 기능 → 스킬에서 업로드하세요. 스킬판에는 부문 용어 팩과 검사기까지 들어 있습니다.

Claude Code에서는 /plugin marketplace add ktr218/civil-engineer-tone 다음 /plugin install civil-engineer-tone@civil-engineer-tone

Claude 스킬 zip 받기
점검 등급(A~D)은 어떻게 매기나요?

글 500자마다 지적 점수를 더합니다. 꼭 고칠 것 5점, 고치면 좋은 것 2점, 참고 0.5점이고 0.5점 미만이면 A입니다. 사람이 쓴 실무 문서는 열에 아홉이 A입니다.

입찰 안내서·서약서처럼 원래 경어로 쓰는 문서는 문서 종류를 내부 보고·메일·안내나 공문으로 고르세요.

모르는 숫자를 지어내지 않나요?

입력에 없는 수치·사업명·법 조항은 ○○ 또는 [확인 필요]로 남깁니다. 결과 뒤에 무엇을 바꿨는지 3~6줄로 알려 줍니다.

위 바로 점검에서 [원문과 수치 대조]를 열고 AI에 넣기 전 글을 넣으면, 바뀌거나 빠진 숫자·단위를 짚어 줍니다. 최종 확인은 작성자가 합니다.

회사 자료를 넣어도 되나요?

대외비·개인정보가 있는 문장은 외부 AI에 넣지 마세요. 말투만 바꿀 때는 사업명·수치를 ○○로 바꿔 넣어도 됩니다.

휴대폰에서도 되나요?

됩니다. [지침 복사하기]를 누른 뒤 AI 앱 입력칸을 길게 눌러 [붙여넣기] 하세요.

어떤 AI에서 되나요?

ChatGPT·Gemini·Claude 등 채팅형 AI라면 어디서나 됩니다. 붙여넣은 대화 안에서는 계속 이 말투로 씁니다.
