# 상하수도 실무 용어집

용어 표기는 실무 문서 관용을 따른다. `일반어 → 실무어` 대응은 3절, 약어는 4절.
정의는 실무 맥락을 짧게 적은 것이며, 법적 정의가 필요하면 해당 법령·기준을 확인한다.

## 1. 상수도

### 1.1 계통·시설
| 용어 | 설명·쓰임 |
|---|---|
| 취수 → 도수 → 정수 → 송수 → 배수 → 급수 | 상수도 계통 순서. 관로도 `도수관로`, `송수관로`, `배수관로`, `급수관`으로 구분 |
| 취수원, 취수장, 취수탑, 취수보 | 원수 확보 시설. `호소수`, `하천표류수`, `복류수`, `지하수` |
| 착수정 | 정수장 첫 공정, 유입 수위·유량 안정 |
| 혼화지, 응집지, 침전지(응집침전지) | 약품 혼화·플록 형성·침전 |
| 여과지 | `급속여과`, `완속여과`, `하부집수장치`, `여재`, `역세척(물+공기 역세척)`, `여재 팽창률`, `트러프` |
| 정수지 | 정수 저류, `소독 접촉시간(CT)` |
| 배출수처리시설 | `배출수지`, `농축조`, `탈수기(벨트프레스·원심탈수)`, `천일건조상` |
| 고도정수처리 | `오존`, `입상활성탄(GAC)`, `막여과` |
| 소독설비 | `액화염소` → `차아염소산나트륨(NaOCl)` 전환 사례 다수 |
| 배수지 | `H.W.L.`, `L.W.L.`, `유효용량`, `계획1일최대급수량의 12시간분 이상` 등 용량 기준 |
| 가압장 | 고지대 급수용, `부스터펌프` |
| 마을상수도, 소규모급수시설 | 지방상수도 미보급 지역 소규모 수도 |
| 광역상수도, 지방상수도 | 공급 주체 구분. `광역 배분량`, `지방 정수장` |

| 복선화, 비상연계 | 단일 관로 사고 대비 이중화·타 계통 연계 |
