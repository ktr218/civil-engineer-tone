# 에너지부문 용어 팩 (발전 · 집단에너지 · 에너지사용계획 · 기전)

근거: 사내 공유 실무 문서 38건(발전·신재생·집단에너지 사업의 보고서, 시방서, 에너지사용계획, 검토의견·조치계획, 추진보고, 공문)의 용어 빈도와 표기. 2026-11 자료지도 추가 조사에서 규칙에 쓰지 않은 문서 49건(에너지 26, 기계·전기·계측 23)으로 기전 용어를 보강했다. 원문·사업명은 싣지 않는다. 상태: 실무 문서 근거 · 부문 검토 대기.

| 용어 | 설명·쓰임 |
|---|---|
| 발전 | `발전소`, `발전설비`, `발전사업`, `양수발전소`, `지하발전소`, `태양광`, `해상풍력`, `LNG`, `호기` |
| 규모 표기 | `○○MW(○MW×○○기)`, `○○MW(○○MW × 2기)` — 설비용량은 MW, 기수 병기 |
| 에너지량 | `MWh/년`, `kWh/년`, `Gcal/년`, `TOE/년` — 연간 단위를 괄호나 `/년`으로 명시 |
| 에너지사용계획 | `에너지사용계획(서)`, `에너지원별`, `전력부하`, `수요예측`, `연료사용량`, `전력사용량`, `에너지이용효율`, `에너지절감` |
| 집단에너지 | `집단에너지사업`, `집단에너지시설`, `열수요`, `폐열회수`, `수급체계` |
| 절감 | `절감량`, `절감율`, `저감량`, `회수기간`, `CO2 저감량` |

| VE 제안명 | `~를 단순화하자`, `~를 적용하자` (상위 규칙 V 유형 그대로) |

## 기계·전기·계측 (기전)
처리장·펌프장·발전소에 공통으로 쓰인다. 물산업 시설의 전기·계측 용어도 이 절을 따른다.

| 용어 | 설명·쓰임 |
|---|---|
| 수변전 | `수전설비(22.9kV)`, `수전방식`, `수전용량(kVA)`, `변압기 정격용량`, `예비변압기`, `한전 인입`, `특별고압` |
| 보호 | `차단기(MCCB·ELB·ACB)`, `단락전류(kA)`, `과전류`, `보호협조`, `서지보호장치(SPD)`, `공칭방전전류`, `피뢰설비` |
| 접지 | `공통통합접지`, `독립접지`, `접지극`, `접지저항`, `접지설계` |
| 전원 | `전압강하(%)`, `역률개선 콘덴서`, `고조파`, `무정전전원장치(UPS)`, `비상발전기`, `예비전원`, `직류전원설비` |
| 동력·제어 | `MCC`, `전동기기동반`, `현장제어반(현장조작반)`, `분전반`, `인버터`, `소프트 스타터` |
| 계측제어 | `계측제어설비`, `감시제어설비`, `PLC`, `HMI`, `TM/TC`, `유량계`, `수위계`, `통합운영` |
| 시험·도서 | `공장시험`, `공인기관시험`, `시운전`, `성능보장`, `제작도서`, `내선규정(조항 번호)`, `KS C IEC ○○○○○` |
| 계산서 표기 | 변수 정의에 대괄호 단위를 쓴다: `PB : 변압기의 정격용량 [kVA]`, `I : 단락전류 [kA]`. 결과는 `1.03kW → 표준사양 ○kW 선정` |
| 의견·조치 | 심의의견은 `~누락`, `~적정한가?` 같은 점검 질문형도 쓰고, 조치는 `~내선규정 ○○○○에 근거하여 선정하였음` |
