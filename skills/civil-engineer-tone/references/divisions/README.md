# 부문별 용어 팩

DIDAS AI 스퀘어의 활용 부문 구분을 따른다. 공통 문체·기호·단위 규칙은 상위 폴더 파일을 쓰고, 이 폴더는 부문별 전문 용어와 관례만 담는다.

| 파일 | 부문 | 주요 분야 | 상태 |
|---|---|---|---|
| `water.md` | 물산업부문 | 상수도, 하수도, 정수·하수처리 | 실무 문서 약 340건 근거 |
| `transport.md` | 교통부문 | 도로, 공항, 철도, 교통 | 실무 문서 83건 근거 · 부문 검토 대기 |
| `infra.md` | 인프라부문 | 수자원·하천, 환경평가, 항만·해안, 구조, 지반·터널 | 실무 문서 210건 근거 · 부문 검토 대기 |
| `urban.md` | 도시부문 | 도시계획, 단지, 조경, 레저 | 실무 문서 38건 근거 · 부문 검토 대기 |
| `energy.md` | 에너지부문 | 발전, 집단에너지, 에너지사용계획, 기전 | 실무 문서 38건 근거 · 부문 검토 대기 |
| `cm.md` | CM·건설부문 | 건설사업관리, 감리, 시공 | 실무 문서 40건 근거 · 부문 검토 대기 |
| `support.md` | 지원부문 | 사업관리, 계약, 해외 | 초안 · 부문 검토 필요 |

## 팩 작성 규칙
- 형식: `| 용어 | 설명·쓰임 |` 표, 그리고 `일반어 → 실무어` 표.
- 근거가 된 문서 수와 종류를 맨 위에 적는다. 원문·사업명·수치는 넣지 않는다.
- 공통 규칙 검증: 다른 부문 실무 문서 409건을 검사기에 넣으면 86%가 A등급(상하수도 88%)으로, 끝맺음·기호·단위 규칙은 전 부문에 그대로 적용된다.
- 부문 팩은 부문 담당자가 실제 성과품과 대조해 고친 뒤 상태를 바꾼다(작업 브랜치 `division/<부문>` → PR).
