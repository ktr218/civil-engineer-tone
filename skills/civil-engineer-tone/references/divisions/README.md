# 부문별 용어 팩

DIDAS AI 스퀘어의 활용 부문 구분을 따른다. 공통 문체·기호·단위 규칙은 상위 폴더 파일을 쓰고, 이 폴더는 부문별 전문 용어와 관례만 담는다.

| 파일 | 부문 | 주요 분야 | 상태 |
|---|---|---|---|
| `water.md` | 물산업부문 | 상수도, 하수도, 정수·하수처리 | 실무 문서 약 340건 근거 |
| `transport.md` | 교통부문 | 도로, 철도, 교통 | 초안 · 부문 검토 필요 |
| `infra.md` | 인프라부문 | 구조·교량, 수자원·하천, 항만·해안, 환경평가 | 초안 · 부문 검토 필요 |
| `urban.md` | 도시부문 | 도시계획, 단지, 조경, 건축 | 초안 · 부문 검토 필요 |
| `energy.md` | 에너지부문 | 신재생, 송변전, 플랜트 부대토목 | 초안 · 부문 검토 필요 |
| `cm.md` | CM·건설부문 | 건설사업관리, 감리, 시공 | 초안 · 부문 검토 필요 |
| `support.md` | 지원부문 | 사업관리, 계약, 해외 | 초안 · 부문 검토 필요 |

## 팩 작성 규칙
- 형식: `| 용어 | 설명·쓰임 |` 표, 그리고 `일반어 → 실무어` 표.
- 근거가 된 문서 수와 종류를 맨 위에 적는다. 원문·사업명·수치는 넣지 않는다.
- 초안 팩은 부문 담당자가 실제 성과품과 대조해 고친 뒤 상태를 바꾼다(작업 브랜치 `division/<부문>` → PR).
