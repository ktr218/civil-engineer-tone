# 교통부문 용어 팩 (도로 · 철도 · 교통)

상태: 초안 · 부문 검토 필요. 일반 실무 지식으로 작성했으며 실무 문서 근거 보강 예정.

## 1. 도로
| 용어 | 설명·쓰임 |
|---|---|
| 설계속도, 설계구간 | `설계속도 80km/h`, 구간별 설정 |
| 평면선형 | `최소곡선반경 R=280m`, `완화곡선`, `클로소이드 A=○○` |
| 종단선형 | `종단경사 i=3.5%`, `종단곡선 L=○○m`, `정점(VIP)` |
| 횡단구성 | `차로폭 3.5m`, `길어깨`, `중앙분리대`, `편경사 6%` |
| 시거 | `정지시거`, `앞지르기시거` |
| 교차로·IC | `평면교차로`, `입체교차로`, `IC·JCT`, `연결로`, `가감속차로` |
| 교통량 | `AADT(연평균일교통량)`, `설계시간교통량(DHV)`, `K계수`, `D계수` |
| 서비스수준 | `LOS A~F`, `V/C비` |
| 포장 | `아스팔트 콘크리트 포장`, `콘크리트 포장`, `표층·기층·보조기층`, `포장두께 설계` |
| 토공 | `절토·성토`, `토공 유용`, `사면 안정`, `연약지반 처리` |
| 배수 | `측구`, `횡배수관`, `집수정` |
| 부대시설 | `방호울타리`, `차선도색`, `도로표지`, `가로등` |
| 행정 | `도로구역 결정`, `도로점용허가`, `도로관리심의` |
