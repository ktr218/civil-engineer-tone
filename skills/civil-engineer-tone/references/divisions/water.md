# 물산업부문 용어 팩 (상수도 · 하수도 · 정수 · 하수처리)

근거: 실무 문서 본문 약 340건(물산업부문) 분석. 2026-11 자료지도 추가 조사에서 규칙에 쓰지 않은 문서 32건(상하수도·수처리 18, 건축 14)으로 건축 용어를 보강했다. 공통 규칙은 `../style-taxonomy.md`, 공통 용어는 `../glossary.md`. 처리장·펌프장의 전기·계측 용어는 `energy.md`의 기전 절을 쓴다.

## 1. 상수도

### 1.1 계통·시설
| 용어 | 설명·쓰임 |
|---|---|
| 취수 → 도수 → 정수 → 송수 → 배수 → 급수 | 상수도 계통 순서. 관로도 `도수관로`, `송수관로`, `배수관로`, `급수관`으로 구분 |
| 취수원, 취수장, 취수탑, 취수보 | 원수 확보 시설. `호소수`, `하천표류수`, `복류수`, `지하수` |
| 착수정 | 정수장 첫 공정, 유입 수위·유량 안정 |
| 혼화지, 응집지, 침전지(응집침전지) | 약품 혼화·플록 형성·침전 |
| 여과지 | `급속여과`, `완속여과`, `하부집수장치`, `여재`, `역세척(물+공기 역세척)`, `여재 팽창률`, `트러프` |
| 정수지 | 정수 저류, `소독 접촉시간(CT)` |
| 배출수처리시설 | `배출수지`, `농축조`, `탈수기(벨트프레스·원심탈수)`, `천일건조상` |
| 고도정수처리 | `오존`, `입상활성탄(GAC)`, `막여과` |
| 소독설비 | `액화염소` → `차아염소산나트륨(NaOCl)` 전환 사례 다수 |
| 배수지 | `H.W.L.`, `L.W.L.`, `유효용량`, `계획1일최대급수량의 12시간분 이상` 등 용량 기준 |
| 가압장 | 고지대 급수용, `부스터펌프` |
| 마을상수도, 소규모급수시설 | 지방상수도 미보급 지역 소규모 수도 |
| 광역상수도, 지방상수도 | 공급 주체 구분. `광역 배분량`, `지방 정수장` |

### 1.2 관망·운영
| 용어 | 설명·쓰임 |
|---|---|
| 상수관망, 관망도 | 관로 네트워크, `관망도 신뢰성` |
| 블록시스템(대·중·소블록) | `블록분할`, `블록고립`, `블록유입유량`, `단계시험(Step Test)` |
| 유수율 / 무수율 / 누수율 | `유수율(%)=유수수량÷생산량`. 무수수량은 `불감수량`, `부정사용`, `공공수량` 포함 |
| 급수보급률 | 급수인구÷총인구 |
| 급수량원단위 / 사용량원단위 | `ℓ/인·일`, `Lpcd`. 생산량÷급수인구 / 유수수량÷급수인구 |
| 계획1일최대급수량, 계획1일평균급수량 | 시설용량 결정 기준. `첨두부하율` |
| 수압(저수압·고수압 지역) | `최소동수압`, `최대정수압`, `감압밸브` |
| 노후관, 경과년수 | `20년 경과 관로 비율`, `내용연수` |
| 관상태 평가 | `관상태직접평가`, `관체 시편 채취`, `성능진단(노후도·수압·수질)` |
| 밸브류 | `제수밸브`, `이토밸브(이토변)`, `공기밸브(공기변)`, `역지밸브`, `보수밸브`, `제수밸브 키보호통`, `밸브실` |
| 소화전 | `지상식`, `지하식` |
| 유량계 | `전자식`, `초음파식`, `블록유량계`, `TM/TC` |
| 관로 표시 | `관로표지못`, `관로표석`, `경고테이프`(탐지형) |
| 복선화, 비상연계 | 단일 관로 사고 대비 이중화·타 계통 연계 |
| 급수체계조정 | 정수장·배수지 공급구역 재편 |
| 수요관리계획 | 절수, 누수저감, 대체수자원 |

### 1.3 계획·진단
| 용어 | 설명·쓰임 |
|---|---|
| 수도정비계획(수도정비기본계획) | 10년 단위 수립, 5년마다 타당성 검토. `초안 → (안) → 최종` |
| 기술진단 | `정수시설 기술진단`, `상수도관망 기술진단`, 5년 주기 |
| 지방상수도 현대화사업 | `노후 상수관망 정비`, `노후 정수장 정비` |
| 계획급수구역, 계획급수인구 | `행정구역 → 계획급수구역 → 급수구역` |
| 용수수급전망 | 수요량 vs 공급량, `부족량` |
| 사회적유입인구(사회적인구), 자연적인구 | 개발계획 반영 인구 / 추세 인구 |
| 기타용수 | 군부대·공공시설 등 |
| 시설용량, 가동률(평균·최대) | `평균가동률 55.0%` |

## 3. 건축 (물산업부문 건축부)
처리장 관리동·펌프장 상부 건물과 건축 시방에서 쓴다. 시방 문장은 S 유형(`~한다`, `~하여야 한다`)을 따른다.

| 용어 | 설명·쓰임 |
|---|---|
| 기준 | `KCS 41 ○○ ○○`(건축공사 표준시방서 코드), `KS ○ ○○○○`, `공사시방서에 따른다` |
| 바탕 | `바탕처리`, `바탕면`, `물축이기`, `들뜸·균열 검사`, `바탕 모르타르` |
| 마감 | `미장`, `타일 떠붙임·압착붙임`, `뿜칠`, `석고보드`, `줄눈`, `실리콘·우레탄·실란트`, `에폭시` |
| 도장 | `도장공사`, `도막 양생(건조)시간`, `내후성`, `내약품성`, `지정색` |
| 결함 | `들뜸`, `균열`, `박리`, `백화`, `얼룩` |
| 승인 | `견본`, `견본품 설치`, `담당원(감리자)의 승인`, `제품 관련 자료 제출` |
| 규모 | `건축면적`, `연면적(㎡)`, `건폐율(%)`, `용적률(%)`, `층수` |
| 인허가 | `건축법 제29조 건축협의`, `건축허가`, `BF(장애물 없는 생활환경) 인증` |
