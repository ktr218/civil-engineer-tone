# 단위·수치·날짜·출처 표기법

값은 바꾸지 않는다. **표기만** 통일한다.

## 1. 단위

| 대상 | 실무 표기 | 피할 표기 |
|---|---|---|
| 용량·유량(일) | `㎥/일` | `m3/day`, `m³/d`, `톤/일`(통계 인용 외), `CMD` |
| 유량(분·초) | `㎥/min`, `㎥/s` | `m3/min`, `cms` |
| 원단위 | `ℓ/인·일` 또는 `Lpcd` | `L/인/일`, `리터/인/일` |
| 관경 | `D400mm`, `Ø400mm` | `지름 400mm`, `400파이` |
| 연장 | `L=13.036km`, `L=850m` | `길이 13km` |
| 높이·폭·깊이 | `H=2.0m`, `B=1.5m` | `높이 2m` (표·제원) |
| 면적 | `㎢`, `㎡`, `ha` | `km2`, `m2` |
| 강우 | `㎜`, `㎜/hr` | `mm/h`(혼용 금지) |
| 지하수위 | `GL-2.8m` | `지하 2.8m` |
| 경사 | `S=1:0.3`, `I=5‰` | `기울기 0.3` |
| 강도 | `fck=27MPa` | `27메가파스칼` |
| 비율 | `%`, 포인트 차이 `%p` | `퍼센트` |
| 수질 | `㎎/L`, `NTU` | `ppm`(혼용 금지) |
| 인구 | `인`, `세대` | `명`(발표 시나리오 제외) |
| 개소 | `개소`, `기`, `대`, `식`, `본` | `곳`, `개` |

- 숫자와 단위 사이는 붙인다: `5,000㎥/일`, `3.4㎞`.
- 제원 기호 `=` 앞뒤는 붙인다: `Q=5,000㎥/일`. 단 양식 개요표의 `사 업 명 : ○○`처럼 콜론 앞뒤는 띄운다.

## 2. 금액

- 문서 하나에 한 단위: 계획·장표는 `백만원`/`억원`, 계약심사·내역은 `천원`/`원`.
- 표 우측 상단에 `(단위 : 백만원)`.
- 감액 `△`, 증액 `증` 또는 `+`: `△120,000천원(△1.5%)`, `증85,000천원`.
- 재원협의·금액조정 표에서는 `감) 22백만원`, `증) 1백만원` 표기도 쓴다. 한 표 안에서는 한 방식으로 통일한다.
- 금액 조정 문장: `5,484백만원 → 2,562백만원으로 조정`, 요율은 `요율(7.54%)`.
- 재원 비율: `국비 50%, 도비 15%, 군비 35%` 또는 `(재원 비율) 국비 67%, 도비 7%, 군비 26%`.
- 부가세: `(부가세 포함)`, `(VAT 별도)`.

## 4. 표·그림

- 번호: `<표 3.2-1>`, `<그림 2.1-6>` (장.절-순번).
- 단위: 표 우측 상단 `(단위 : 인, %)`.
- 출처: 표 하단 `자료) 하수도통계(2024, 환경부)`.
- 비고 열: 근거·산식 요약 (`생산량÷급수인구`).
- 구분 열 첫 칸은 `구 분`, 합계 행은 `계` 또는 `합 계`.
